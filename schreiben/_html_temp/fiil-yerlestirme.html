Fiil Yerleştirme (Lückentext) Çalışma Dosyası

Sınav: 29 Nisan 2026 — Almanca, A2 ağırlıklı + B1 dokunuşlu

Amaç: Boşluğa fiili doğru çekimle koyabilmek. En sık test edilen 6 yapı + tanıma rehberi + gerçek B1 kitabı alıştırmaları (cevap anahtarıyla).

0. Sınavda Boşluğu Görünce Karar Ağacı

Boşluğun YANINDA / CÜMLESİNDE ne var?

→ "haben" / "ist" / "bin" / "war" → PERFEKT (Partizip II gerek)
→ "wird" / "wurde" → PASSIV (Partizip II gerek)
→ "sich" / "mich" / "dich" → REFLEXIVE (sich-fiili çekim)
→ "weil" / "dass" / "wenn" → fiil cümlenin SONUNDA
→ "möchte" / "kann" / "muss" / "soll" / "will" / "darf" → MODAL → boşluğa INFINITIV gelir
→ "der/die/das" virgülden sonra → RELATİVSATZ → fiil sonda
→ Cümle "Ich hätte / Könnte ...?" → KONJUNKTIV II höflich
→ Geçmiş haber metni / biyografi → PRÄTERITUM (war/hatte/ging/kam/sah)
→ Boşluk "ge___t" / "ge___en" şeklinde → PARTIZIP II (Perfekt için)
→ Cümle Akkusativ (mich/dich) ya da Dativ (mir/dir) reflexivpronomen → sich seçimi

1. Perfekt — haben mi sein mi? (En sık test)

Kural:
- sein: hareket (gehen/fahren/kommen/fliegen/reisen/laufen) + durum değişimi (werden/aufstehen/einschlafen) + bleiben + sein
- haben: geri kalan ~%85'i

Yapı: haben/sein (2. pozisyon) + Partizip II (sonda)

Fiil tipi Partizip II kuralı Örnek
Düzenli (regelmäßig) ge + Stamm + t machen → gemacht / spielen → gespielt
Düzensiz (unregelmäßig) ge + (kök değişebilir) + en gehen → gegangen / sehen → gesehen
Trennbar (anrufen) Ön ek + ge + Stamm + (t/en) anrufen → angerufen / einladen → eingeladen
-ieren (studieren) ge YOK + Stamm + t studieren → studiert / telefonieren → telefoniert
be-/ver-/er- ile başlayan ge YOK besuchen → besucht / verstehen → verstanden

5 örnek:
- Ich habe Deutsch gelernt. (lernen — düzenli, haben)
- Wir sind nach Berlin gefahren. (fahren — düzensiz, sein-hareket)
- Er hat mich angerufen. (anrufen — trennbar, haben)
- Sie hat in München studiert. (studieren — -ieren, ge YOK, haben)
- Sie ist um 7 Uhr aufgestanden. (aufstehen — sein-durum değişimi)

2. Modalverben + Trennbare Verben

2a. Modalverben Präsens çekim

können müssen sollen wollen dürfen mögen möchten
ich kann muss soll will darf mag möchte
du kannst musst sollst willst darfst magst möchtest
er/sie/es kann muss soll will darf mag möchte
wir können müssen sollen wollen dürfen mögen möchten
ihr könnt müsst sollt wollt dürft mögt möchtet
sie/Sie können müssen sollen wollen dürfen mögen möchten

Yapı: Modal (2. poz.) + Infinitiv (sonda)
- Ich muss heute lange arbeiten.
- Sie kann sehr gut schwimmen.
- Wir möchten ein Bier bestellen.

2b. Modalverben Präteritum (B1 — biyografi/haber metnine çıkar)

konnte musste sollte wollte durfte mochte
ich/er/sie konnte musste sollte wollte durfte mochte
du konntest musstest solltest wolltest durftest mochtest
wir/sie/Sie konnten mussten sollten wollten durften mochten

Umlaut kaybolur Präteritum'da: könn → konnt / müss → musst / dürf → durft / mög → mocht.

2c. Trennbare Verben

Liste (en sık): anrufen, einladen, aufstehen, einkaufen, ankommen, abfahren, mitkommen, ausgehen, fernsehen, anziehen, ausziehen, anfangen, aufhören, abholen, weiterlernen, zurückkommen, vorbereiten

3 zaman test:
- Präsens: Ön ek fiilden ayrılır, sonda. → Ich rufe dich an.
- Perfekt: Ön ek + ge + Stamm. → Ich habe dich angerufen.
- Modal ile: Ayrılmaz, infinitiv. → Ich muss dich anrufen.

Boşluk testleri:
- Ich ___ um 7 Uhr . (aufstehen, Präsens) → "stehe ... auf"
- Er ___ mich gestern . (anrufen, Perfekt) → "hat ... angerufen"
- Wir wollen morgen ___. (einkaufen, modal) → "einkaufen"

3. Reflexive Verben (sich + Akk/Dat)

Reflexivpronomen tablosu:

Şahıs Akkusativ Dativ
ich mich mir
du dich dir
er/sie/es sich sich
wir uns uns
ihr euch euch
sie/Sie sich sich

Akkusativ vs Dativ — kural:
- Akkusativ (çoğu): cümlede başka nesne yok. → Ich freue mich. / Ich interessiere mich für Musik.
- Dativ: cümlede zaten Akkusativ nesnesi var. → Ich wasche mir die Hände. / Ich putze mir die Zähne.

En sık reflexive fiiller:
- Akkusativ: sich freuen (auf/über), sich interessieren (für), sich treffen, sich beeilen, sich konzentrieren, sich entschuldigen, sich erinnern, sich ärgern (über), sich vorstellen
- Dativ: sich (Dat) etw. (Akk) merken / kaufen / ansehen / vorstellen

5 örnek (B1 PDF1 s.12 + Spektrum A2+ s.95):
- Lukas unterhält sich mit seinem Freund.
- Eva duscht sich und frühstückt.
- Ich ärgere mich oft über die vielen Staus.
- Wir freuen uns auf den Unterricht.
- Ich wasche mir die Hände. (Dativ — Akk nesnesi var: die Hände)

4. Konjunktiv II höflich

Yapı (kibarlık için):
- haben → hätte / hättest / hätte / hätten / hättet / hätten
- sein → wäre / wärest / wäre / wären / wäret / wären
- können → könnte / könntest / könnte / könnten / könntet / könnten
- mögen → möchte / möchtest / möchte / möchten / möchtet / möchten
- werden → würde / würdest / würde / würden / würdet / würden

Diğer fiiller için: würde + Infinitiv (sonda)

Test cümleleri:
- ___ Sie mir helfen? (können kibar) → Könnten Sie mir helfen?
- Ich ___ gern einen Kaffee. (möchten) → möchte
- ___ Sie morgen Zeit? (haben kibar) → Hätten Sie morgen Zeit?
- Ich ___ gern nach Berlin reisen. (werden + Inf.) → würde
- ___ es möglich, dass ___? (sein kibar) → Wäre es möglich, dass ...?

5. Präteritum (B1 — biyografi/haber için kritik)

Düzenli fiiller: Stamm + te + kişi eki
- lernen → ich lernte / du lerntest / er lernte / wir lernten
- arbeiten → ich arbeitete / du arbeitetest (-t fiili → ek "ete")

Düzensiz fiiller (vokal değişimi + ek YOK ich/er):

Mischverben (karışık — vokal değişir + "te" eki):
- denken → dachte / wissen → wusste / kennen → kannte / bringen → brachte

Boşluk testleri:

- Er ___ Germanistik in München. (studieren — düzenli) → studierte

6. Passiv (B1)

Yapı: werden (çekimli) + Partizip II (sonda)

Zaman Form Örnek
Präsens wird/werden + P.II Das Restaurant wird renoviert.
Präteritum wurde/wurden + P.II Das Restaurant wurde 1658 gekauft. (B1 PDF1 s.40)
Perfekt ist/sind + P.II + worden Das Restaurant ist renoviert worden.

Boşluk testleri:
- Die Kartoffeln ___ geschält. (werden Präsens) → werden
- Das Café ___ 1876 eröffnet. (werden Prät.) → wurde
- Der Roman ___ 2009 verfilmt ___. (Perfekt) → ist ... worden

8. Gerçek Alıştırma 1: Markus'un Günü (B1 PDF1 s.10, Aufgabe 2 — kısaltılmış)

Yönerge: Lesen Sie den Bericht von Markus und ergänzen Sie die Verben in der richtigen Form. (Boşluğa fiili Präsens ile koy.)

Fiil havuzu: stehen ... auf — fahren — dauern — warten — stehen — arbeiten — beginnen — beantworten — lesen — haben — sprechen — lösen — sammeln — machen — essen — teilnehmen — gehen — sauber machen — waschen — gehören

Metin (10 boşluk seçildi):

  1. Montags bis freitags ___ ich um 7.00 Uhr ___. (aufstehen)
  2. Gegen 8.00 Uhr ___ ich mit dem Auto ins Büro. (fahren)
  3. Das ___ normalerweise 15 Minuten. (dauern)
  4. Ich muss ein paar Minuten auf den Fahrstuhl ___. (warten)
  5. Meine Arbeitszeit ___ um 9.00 Uhr. (beginnen)
  6. Zuerst ___ ich meine E-Mails. (beantworten)
  7. Jeden Mittwoch ___ wir eine Besprechung. (haben)
  8. In der Sitzung ___ wir über Projekte. (sprechen)
  9. Nach der Arbeit ___ ich ins Fitnessstudio. (gehen)
  10. Ab und zu muss ich meine Wohnung ___. (sauber machen)

9. Gerçek Alıştırma 2: Jörg Maurer Biyografisi (B1 PDF1 s.20, Aufgabe 17 — birebir)

Yönerge: Lesen Sie die Kurzbiografie und ergänzen Sie die Verben im Präteritum.

Fiil havuzu: verlassen — studieren — schreiben — abschließen — arbeiten — entwickeln — leiten — erscheinen — sein — gehen — verfilmen — erhalten

Metin:

Jörg Maurer wurde 1953 im bayerischen Oberland geboren. Nach der Schulzeit ___ (1) er Garmisch-Partenkirchen und ___ (2) in München Germanistik. Seine Magisterarbeit ___ (3) er über den deutschen Schriftsteller Arno Schmidt. Er ___ (4) sein Studium mit Erfolg ab und ___ (5) einige Jahre als Lehrer für Deutsch und Englisch. Zur gleichen Zeit ___ (6) er eine neue Form des Kabaretts und ___ (7) ein kleines Theater. Sein erster Kriminalroman „Föhnlage" ___ (8) 2009. Da ___ (9) auch die Geburtsstunde von Kommissar Jennerwein. Rainer Kaufmann ___ (10) das Buch verfilmen — die Verfilmung ___ (11) im Bayerischen Rundfunk gezeigt. Jörg Maurer ___ (12) für seine Krimis zahlreiche Preise.

Cevap Anahtarı — Alıştırma 2 (B1 PDF1 s.20'den birebir)

(1) verließ — (2) studierte — (3) schrieb — (4) schloss ... ab (trennbar Prät.) — (5) arbeitete — (6) entwickelte — (7) leitete — (8) erschien — (9) war — (10) ging (… verfilmen) — (11) wurde (… verfilmt — Passiv) — (12) erhielt

Not: Sınavda biyografi tipi metin gelirse Präteritum beklenir (war/hatte/ging/kam/sah/schrieb…). Konuşma diline (Perfekt'e) çevirme.

11. Mini Pratik — 15 Hızlı Boşluk (Karışık)

Cevapları kapat, çöz, sonra kontrol et.

  1. Ich ___ gestern einen Brief geschrieben. (haben/sein) → habe
  2. Sie ___ nach Berlin gefahren. (haben/sein) → ist
  3. ___ Sie mir helfen? (kibar — können) → Könnten
  4. Wenn ich Zeit ___, lese ich. (haben Präs.) → habe
  5. Ich freue ___ auf das Wochenende. (refleksiv) → mich
  6. Wir wollen morgen ___. (einkaufen, modal) → einkaufen
  7. Er ___ als Lehrer (arbeiten Prät.) → arbeitete
  8. Goethe ___ 1749 in Frankfurt geboren. (werden Prät.) → wurde
  9. Das Buch ___ 2009 ___. (erscheinen Prät.) → erschien
  10. Ich lerne Deutsch, ___ ich nach Deutschland reisen ___. (weil + möchten) → weil ... möchte
  11. Das ist der Mann, ___ das Buch geschrieben hat. (Relativ Nom.) → der
  12. Das Restaurant ___ 1658 gekauft. (Passiv Prät.) → wurde
  13. Ich wasche ___ die Hände. (refleksiv Dat.) → mir
  14. Ich ___ um 7 Uhr ___. (aufstehen Präs.) → stehe ... auf
  15. Sie ___ mit Freunden ___. (telefonieren Perfekt) → hat ... telefoniert (-ieren → ge YOK)

12. Sınav Günü Hızlı Kontrol

Boşluğu doldurmadan önce 5 saniye sor:

  1. Hangi zaman? (Präs / Prät / Perfekt / Passiv / Konjunktiv II)
  2. Cümlede modal var mı? → varsa boşluğa Infinitiv
  3. Yan cümle bağlacı var mı (weil/dass/wenn/damit/Relativ)? → fiil sonda
  4. haben mi sein mi? (hareket/durum değişimi → sein)
  5. Trennbar mı? → Präsens'te ön ek sonda, Perfekt'te ge ortada
  6. -ieren ile mi bitiyor? → Perfekt'te ge YOK
  7. Reflexive mi? → cümlede başka Akkusativ var mı? (Dat/Akk seçimi)

Mottovo: Tanı → Forma karar ver → Yaz → Cümleyi tekrar oku, fiil pozisyonu doğru mu kontrol et.
